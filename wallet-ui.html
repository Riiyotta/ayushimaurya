Wallet UI designed with Figma Make AI

I wanted to see how AI tools could speed up my UI work, so I tried building a wallet card interaction with Figma Make.

01How I built it

From a prompt to a polished interaction

Claude wrote the first draft

I first asked Claude to generate the HTML code for the card interaction. It quickly gave me a working structure for the component.

Refining it in Figma Make

I imported that HTML file into Figma Make and used it as a base to refine the interface.

Design polish

Then I worked on the layout, spacing and visual hierarchy so the component looks clean and is easy to use.

What I learned

AI tools got me from an idea to a visual concept faster. The design decisions that shaped the final result were still mine.
